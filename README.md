# Enterprise Full-Stack E-Commerce Platform

A production-ready, highly modular E-Commerce platform built with a monorepo architecture.

## Platform Features
- **Authentication & RBAC**: OAuth2, JWT Refresh Tokens, Role-Based Access Control.
- **Product Catalog Engine**: Multi-category hierarchies, dynamic SKU variants, stock reservation locks.
- **Shopping Cart & Pricing Engine**: Real-time tax calculator, coupon engine, dynamic tier discounts.
- **Order Management System (OMS)**: State machine pipeline (Pending -> Paid -> Shipped -> Completed).
- **Payment Adapters**: Stripe, PayPal, Mock Gateway integration with webhook signature verification.
- **Analytics & Admin Panel**: Real-time KPIs, inventory turnover, customer cohorts, revenue charts.
- **Test Automation**: 5+ comprehensive test suites covering core domain modules.
